
## Hand Gesture Pong 🎮🖐️

A fun Pong game controlled using hand gestures built with Python, OpenCV, MediaPipe, and Pygame.
Move the paddles using your index finger detected through your webcam.

## Features
Real-time hand tracking using MediaPipe
Webcam input with OpenCV
Smooth game rendering using Pygame
Two-player gesture control
Ball collision and score tracking
Simple and interactive gameplay
## Technologies Used
Python
OpenCV
MediaPipe
Pygame
## Installation
1. Clone the Repository
git clone https://github.com/Coderyash05/hand-gesture-pong.git
cd hand-gesture-pong
2. Install Dependencies
pip install opencv-python mediapipe pygame
## Run the Game
python main.py
## How to Play
Launch the game.
Allow webcam access.
Use your index finger to move the paddle vertically.
Left hand controls the left paddle.
Right hand controls the right paddle.
Try to stop the ball and score against your opponent.
📷 Controls
Gesture	Action
Move Index Finger Up	Paddle Moves Up
Move Index Finger Down	Paddle Moves Down
